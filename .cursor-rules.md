# Cursor Rules for iCompass Project

## Protected Files - NEVER Modify

Cursor must **NEVER** modify these files without explicit user permission:

- `src/integrations/supabase/client.ts` - Core Supabase client (critical for auth)
- `scripts/seed-admin.ts` - Admin user seeding script
- `recovery/*` - All recovery scripts
- `.env` - Environment variables (ask before editing)
- `supabase/migrations/*.sql` - Database migrations (ask before editing)

## Code Style Rules

1. **ESM Modules Only**
   - Never use `require()` in `.ts` or `.mjs` files
   - Always use `import` statements
   - If you need CommonJS, use `.cjs` extension

2. **Environment Variables**
   - Only use `VITE_` prefixed variables in frontend code
   - Never expose `SUPABASE_SERVICE_ROLE_KEY` to frontend
   - Always validate env vars at runtime

3. **Supabase Client**
   - Always use `persistSession: true` and `autoRefreshToken: true`
   - Never override auth settings without good reason
   - Always export a single shared client instance

4. **Error Handling**
   - Never silently swallow Supabase errors
   - Always show user-friendly error messages
   - Always log errors to console for debugging

5. **Type Safety**
   - Always use TypeScript types
   - Never use `any` unless absolutely necessary
   - Regenerate Supabase types after schema changes

## Before Making Changes

1. **Check for existing implementations** - Don't duplicate code
2. **Verify environment variables** - Ensure .env is correct
3. **Test locally** - Run `npm run dev` before committing
4. **Check migrations** - Ensure database schema is up to date

## Common Pitfalls to Avoid

- ❌ Don't use `require()` in ESM files
- ❌ Don't modify Supabase client auth settings
- ❌ Don't hardcode API keys or secrets
- ❌ Don't create duplicate coordinate input fields
- ❌ Don't remove error handling
- ❌ Don't break session persistence

## When in Doubt

- Ask the user before making breaking changes
- Preserve existing functionality
- Add new features without removing old ones
- Test thoroughly before marking as complete
