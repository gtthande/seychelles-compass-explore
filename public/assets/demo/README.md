## Image Specifications

All demo images should be:
- **Logo**: 200x200px, PNG format with transparent background
- **Cover**: 1200x600px, JPG format
- **Gallery**: 800x600px, JPG format

## Usage

These images are automatically referenced when the demo data seeding script runs. To add real images:

1. Replace the placeholder files with actual business photos
2. Maintain the same filenames
3. Ensure proper image optimization for web use

## Note

In a production environment, these images would be uploaded to Supabase Storage and referenced by their storage URLs rather than local file paths.
